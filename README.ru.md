# Placitum captcha

[English](README.md) · Русский

Капча Placitum: проверка входа, которая требует доказать, что клиент — человек, когда на это есть повод.

Один образ, два процесса. Инспектор на шине решает `allow`, `redirect` или `deny`; сервис виджета
показывает проверку и выписывает клиенту куку пропуска. Ключ у них общий, и это единственное, чем
они связаны.

```
модуль ──► waf.req.captcha ──► captcha      ── allow | redirect | deny
                                  │
                                  ├── решение: профиль, кука пропуска, бакеты, сигналы соседей
                                  └── бакеты и реестр -- во внутреннем Redis

клиент ──► /waf/captcha ──► captcha-http    ── виджет, проверка ответа, кука waf_clr
```

## Что она умеет

- **Бакеты по осям** — адрес, подсеть, система, сессия — на GCRA во внутреннем Redis: один
  писатель на все экземпляры и одна сумма на всех.
- **Провайдеры**: своя картинка или внешние — Turnstile, reCAPTCHA, hCaptcha, SmartCaptcha.
  Провайдер выбирается профилем, а виджет, который не загрузился, уступает место следующему.
- **Встроенная форма** (`gate.inline`): страница виджета отдаётся телом блокировки, без редиректа.
  Полезно за терминатором TLS или на нестандартном порту, где редирект увёл бы браузер не туда.
- **Сигналы соседей**: другой инспектор может сообщить капче факт о клиенте, а решает, что с ним
  делать, её профиль.
- **Запись исходов** в активные наборы: пропуск, отклонение, блокировка — адресом, подсетью или системой.
- **Наблюдение**: инспектор всегда отвечает `allow` и пишет в аудит, что решил бы, — так пороги
  бакетов калибруют на живом трафике.

## Профили

В образе четыре профиля в `profiles/`; контроллер заменяет их поколением из панели.

| Профиль | Что делает |
| --- | --- |
| `default` | виджет при заполнении бакетов и по сигналу соседа; своя картинка |
| `login` | виджет каждому без пропуска, пропуск недолгий: формы входа и регистрации |
| `form` | как `login`, но страница приходит телом ответа на том же URI |
| `observe` | всегда `allow`, решение, которое было бы принято, — в аудит |

Профиль `_probe` выводится из `default` автоматически для проверки здоровья. Страница виджета на
английском; список `languages` профиля (по умолчанию `en`, `ru`) выбирает язык страницы по
`Accept-Language`.

## Сборка и запуск

```sh
docker build -f deploy/Dockerfile -t placitum/captcha .
```

Инспектор — команда по умолчанию, сервис виджета — `captcha-http` на том же образе. Что нужно
рядом, ключи и настройки — в [INSTALL.ru.md](INSTALL.ru.md).
